# 사업 맥락 (BUSINESS_CONTEXT)

> 기준일: 2026-10-07. 수치·가격·법 상태는 바뀔 수 있다. 중요한 결정 전에 다시 확인하고, 바뀐 내용은 이 문서를 고친다(근거와 날짜 포함).
> 이 문서는 창업자와 Claude가 나눈 논의의 통찰을 모두 담는다. 코드의 기본값, 우선순위, 트레이드오프 판단의 근거로 쓴다.
> 사업 개요서(편집 가능한 문서): https://claude.ai/code/artifact/25054f5f-88b7-4b31-b341-7f6b2413ba05

## 1. 한 줄 정의
PC방에서 손님이 없는 PC가 AI 연산을 '채굴'해 크레딧(사업상 '토큰')을 만들고, 이 크레딧은 Opus·Sonnet 같은 여러 AI 모델로 환전되는 화폐가 된다. 초기 영업은 PC방 사장님에게 집중한다.

## 2. 비전
AI가 버는 돈을 빅테크 몇 곳이 아니라 개인이 나눠 갖는다. 사람이 AI에 내맡겨지지 않고, AI의 생산수단을 함께 소유한다.

## 3. 핵심 전제와 개념
- **전제**: 토큰(크레딧) 자체가 화폐가 된다. 1단위는 표준 AI 연산 단위이고, 모델마다 정해진 환율로 바꿀 수 있다. 원화 하나로 달러·엔화를 각각 다른 환율로 바꾸는 것과 같다.
- **컴퓨팅 본위제**: 금본위제처럼 화폐 가치를 AI 연산에 묶는다.
- **예시 환율표** (1크레딧 = 1달러로 정했을 때, 2026-10 Claude API 정가 기준)

| 바꾸는 모델 | 정가 (100만 토큰당, 입력 / 출력) | 1크레딧으로 입력에 쓰면 | 1크레딧으로 출력에 쓰면 |
|---|---|---|---|
| Claude Opus 5.5 | $4 / $20 | 25만 토큰 | 5만 토큰 |
| Claude Sonnet 5.5 | $2 / $10 | 50만 토큰 | 10만 토큰 |
| Claude Haiku 4.5 | $1 / $5 | 100만 토큰 | 20만 토큰 |

  - 외부 원가 참고: Batch API는 입력·출력 50% 할인, 프롬프트 캐시 읽기는 기본 입력가의 10%.
  - 다른 회사 모델과 PC방에서 돌리는 오픈소스 모델도 같은 방식으로 환율표에 추가한다.
  - 같은 "1토큰"이라도 회사(토크나이저)마다 양이 다르다 → 환율표가 이 차이를 흡수한다.
- 환전만 하는 서비스(예: OpenRouter — 크레딧 하나로 80여 제공사 500개+ 모델)는 이미 있다. 그래서 이 사업의 차별점은 환전이 아니라 **채굴로 크레딧이 생겨난다**는 점이다.

## 4. 비트코인 채굴과 결정적으로 다른 점 (설계에 반영해야 할 현실)
1. **확인이 어렵다.** 비트코인은 퍼즐 정답을 즉시 확인한다. AI는 노드가 정말 그 모델로 돌렸는지, 더 싼 모델로 대충 답하고 돈만 받는지 가려내기 어렵다 → 검증 체계 필수(카나리아 작업, 서로 다른 매장 간 중복 실행, 모델 지문 확인, 평판, 성숙 기간 동안 보류, 부정 시 회수). Bittensor가 검증자를 따로 두는 이유와 같다.
2. **돈이 손님에게서 나온다.** 비트코인은 사는 사람이 없어도 프로토콜이 새 코인을 찍어 준다. AI 연산은 실제로 사 주는 고객이 있어야 하고, 코인으로 보상하면 그 가치는 시세에 묶인다 → 초기에는 구매자 지불에서 보상하는 마켓플레이스 방식. 새로 발행하는 보상은 시뮬레이션·실험 전용.
3. **집·PC방 컴퓨터는 작다.** 큰 모델 하나를 여러 PC에 쪼개 돌리면 인터넷이 병목이다 → 한 PC에 통째로 들어가는 중소형 오픈소스 모델만 돌린다. 남의 컴퓨터로 데이터가 가는 것을 기업은 꺼린다 → 민감하지 않은 작업, 느려도 되는 대량 작업(번역, 데이터 정리, 이미지 생성 등) 위주.

## 5. 크레딧이 화폐가 되기 위한 조건과 해법
| 조건 | 문제 | 해법 |
|---|---|---|
| 표준 단위 | 모델마다 토큰 가치가 다르고 토크나이저도 다르다 | 표준 단위 + 모델별 환율표. 표준을 정하는 쪽이 사실상 중앙은행이다 |
| 가치 유지 | 기술이 좋아질수록 같은 일을 더 싸게 할 수 있어, 그냥 두면 발행이 늘어 가치가 떨어진다 | 비트코인이 채굴 난이도를 올려 발행 속도를 지키듯, 연산 효율이 오르면 1크레딧을 받는 데 필요한 일의 양을 늘린다(난이도 조절) |
| 쓸 곳(태환) | 쓸 데 없는 화폐는 믿음으로만 유지된다 | "1크레딧 = 언제든 정해진 양의 AI 연산" 태환 보장. 시세에만 기대는 기존 코인(TAO, RENDER, AKT)과의 차이다 |

### 1크레딧을 무엇에 묶을지 (미결정 — 코드는 둘 다 지원, 기본은 달러 고정)
- **달러 고정**: 안정적이지만 사실상 선불 충전금에 가깝다. AI 값이 떨어질수록 같은 1크레딧으로 더 많이 쓴다.
- **여러 모델 가격의 평균(IMF SDR 같은 바스켓)**: 진짜 "AI 화폐"에 가깝지만, AI 값이 떨어지면 1크레딧의 달러 가치도 떨어진다.

## 6. 사업 구조: 3층 + 준비금
1. **채굴**: PC방의 손님 없는 PC가 오픈소스 모델 연산을 제공하고 크레딧을 받는다.
2. **발행·조절 (우리 = 중앙은행)**: 발행량, 난이도, 검증.
3. **교환 (우리 = 거래소)**: 크레딧 ↔ 모델 사용 환전.
- 구매자가 원화로 크레딧을 사면 판매 대금은 **준비금**이 된다.
- 오픈소스 모델 작업은 PC방 연산이 처리한다.
- Opus·Sonnet은 가중치가 공개되지 않아 PC방에서 돌릴 수 없다 → 환전 요청이 오면 준비금으로 해당 API를 사서 내준다.
- **뱅크런**: 모두 한꺼번에 Opus로 바꾸면 준비금이 모자란다 → 준비금 비율 가드 + 하루 환전 한도. 이 사업의 진짜 핵심은 준비금 관리와 환율 설정이다.

## 7. 초기 시장: PC방 사장님
첫 영업 대상은 토큰을 사는 쪽이 아니라 연산을 공급할 PC방이다. 채굴은 손님이 없는 PC에서만 돌고, 손님이 앉으면 바로 멈춘다.

### 왜 PC방인가
- 장비값을 이미 냈다(매몰비용). 채굴용 PC를 새로 살 필요가 없다.
- 손님이 없는 시간이 확실하다(새벽, 평일 오전 등).
- 한 곳에 PC가 많다. 매장당 평균 70~100대(머니투데이, 2026-01).
- 일반용 전기를 써서 주택용 누진제가 없다. 반대로 개인이 집에서 돌리면 누진제 때문에 전기요금이 크게 늘어 불리하다.

### 사장님께 하는 제안
- 손님 없는 시간에 PC가 돈을 번다(현금 또는 크레딧으로 정산).
- 손님이 앉으면 자동으로 멈춰 게임에 영향이 없다.
- 설치와 관리는 우리가 맡는다.

### 단위 경제 (가정 포함)
| 항목 (PC 1대·1시간) | RTX 4060 | RTX 4070 |
|---|---|---|
| 대여 시세 (Vast.ai, 2026-10) | $0.08 (약 112원) | $0.136 (약 190원) |
| 전기 사용 (가정) | 0.25 kWh | 0.3 kWh |
| 전기요금 (일반용 92~132원/kWh) | 약 23~33원 | 약 28~40원 |
| 전기요금 뺀 몫 (PC방과 우리가 나눔) | 약 79~89원 | 약 150~162원 |

- 매장 1곳(PC 80대 × 손님 없는 시간 하루 8시간 × 30일 = 19,200시간)이 다 팔리면 월 약 152만~171만 원(4060), 288만~311만 원(4070)이 남는다. 절반만 팔리면 그 절반이다.
- 가정: 환율 1달러 = 1,400원. 전기요금은 2023-05 시행 한전 일반용(갑)Ⅰ 저압(전력량요금 여름 132.4 / 봄·가을 91.9 / 겨울 119.0 원/kWh, 기본요금 6,160원/kW, 부가세 등 별도). 매장 GPU 사양은 확인 전.
- 시세 압력: Salad는 RTX 4060을 시간당 $0.05에 판다 → 더 싸게 팔아야 할 수 있다. 참고로 RTX 4090은 Vast.ai에서 시간당 $0.40~0.56.
- 처리량(tokens/s), 손님 없는 시간 분포, 실제 전력은 미측정 → 파일럿에서 측정해 이 표를 고친다.

### 영업 방법
1. 동네 PC방 1~3곳에 직접 찾아가 파일럿을 제안한다.
2. 실제 수익 기록을 들고 주변 매장으로 넓힌다.
3. PC방 관리 프로그램 회사와 제휴해 한 번에 많은 매장을 연결한다(에이아이브는 PC방 4,000곳을 관리하는 기업과 손잡았다).

## 8. 수익 모델
- **연산 판매 차익**: 구매자에게 받는 값 − PC방에 주는 값. PC방과 나누는 비율은 미정.
- **크레딧 충전(선불)**: 판매 대금은 준비금이 된다.
- **환전 수수료**: 크레딧을 Opus·Sonnet 등으로 바꿀 때.
- **대량 작업 계약**: 번역, 데이터 정리, 이미지 생성처럼 느려도 되는 일을 기업과 계약.
- 통찰: 비트코인 때도 채굴자보다 거래소와 장비 회사가 더 꾸준히 벌었다 → 우리는 채굴자가 아니라 플랫폼(발행·교환)이 된다.

| io.net · Render | 흩어진 GPU를 모아 AI·렌더링 작업에 빌려준다 | 코인 기반, PC방 특화 아님 |
| Vast.ai · Salad | 개인이 GPU를 빌려주고 현금을 받는 마켓 | 화폐 없이 단순 대여 |

차별점: 연산을 화폐로 만들고, 그 화폐를 여러 회사 모델로 환전해 준다 + PC방 특화(손님 우선, 매장 단위 운영).

## 12. 열린 질문 (코드는 설정값으로 열어 두고, 정해지면 이 표를 갱신)
- 크레딧을 처음 사 줄 사람은 누구인가? (개인, 스타트업, 대량 작업이 필요한 기업) — 가장 먼저 답할 질문
- 1크레딧을 달러에 묶을까, 여러 모델 가격 평균에 묶을까?
- PC방 사장님께 현금으로 줄까, 크레딧으로 줄까? 나누는 비율은?
- 매장의 GPU 사양과 손님 없는 시간 분포는? 재부팅하면 PC가 초기화되는가(복원 솔루션)?
- 에이아이브와 경쟁할까, 협력할까?
- 선불 크레딧의 법적 성격(전자금융거래법 등)

## 13. 제품 원칙 (위 내용에서 나온 결론)
1. **손님 경험 > 수익.** 손님이 앉으면 즉시 멈춘다. 의심스러우면 멈춘다.
2. **실제 돈은 법 검토 전 움직이지 않는다.** 테스트 충전과 수동 정산 '기록'만.
3. **숫자는 정직하게.** 사장님 화면의 수익·전기요금은 측정값과 가정을 구분해 보여 준다.
4. **검증 없이 확정 지급 없음.** 노드 수익은 성숙 기간 뒤 확정되고, 부정이 밝혀지면 회수한다.
5. **데이터 최소화.** 프롬프트·출력은 노드에서 메모리 전용, 서버에서 짧게 암호화 보관.
6. **1인이 운영할 수 있는 단순함.** 저비용, 관리 부담 최소.
