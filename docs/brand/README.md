# Spareon 브랜드 자산

사람이 만든 로고 시안(2026-10-10)을 다듬은 정식 자산이다. 화면·문서·설치 프로그램은 여기 있는 파일을 그대로 쓴다. 손으로 다시 그리지 않는다.

## 구성
| 파일 | 용도 |
|---|---|
| `spareon-logo-horizontal-dark.svg` / `-light.svg` | 기본 로고(심볼 + 워드마크 가로). 헤더·문서 머리 |
| `spareon-logo-stacked-dark.svg` / `-light.svg` | 세로 로고. 첫 화면·설치 프로그램·발표 표지 |
| `spareon-mark-dark.svg` / `-light.svg` | 심볼만. 좁은 자리·트레이 아이콘 원본 |
| `spareon-wordmark-dark.svg` / `-light.svg` | 글자만 |
| `spareon-icon.svg` | 앱 아이콘·파비콘(어두운 둥근 사각형 위 심볼) |

`-dark`는 어두운 배경용, `-light`는 밝은 배경용이다. 워드마크는 글꼴 없이도 똑같이 보이도록 윤곽선(path)으로 변환해 두었다.

## 심볼
전원 버튼 기호와 S를 겹친 모양이다. "손님이 없을 때 켜지는 PC"라는 뜻이다.
- 원 위쪽이 열린 자리에 초록 막대(전원)가 선다. 원의 나머지가 S가 된다.
- 다듬은 점: 원본은 S의 꺾이는 두 곳이 각졌고 끝단 자르는 각도가 제각각이었다. 꺾이는 곳을 곡선으로 이었고, 원호 끝은 모두 원의 반지름 방향으로 잘랐다. 위·아래 틈 간격을 같게 맞췄고, 선 굵기를 하나(지름 대비 약 21%)로 통일했다. 전원 막대만 끝이 둥글다.

## 워드마크
- 표기는 `Spareon`(S만 대문자). `Spare`는 바탕 대비색, `on`은 브랜드 초록.
- 글꼴: Inter Tight Bold(SIL OFL), 자간 -2.5%. 웹에서 글자로 쓸 때도 같은 글꼴·자간을 쓴다.

## 색
| 토큰 | 어두운 배경 | 밝은 배경 |
|---|---|---|
| 바탕 | `#0E1A15` | `#FFFFFF` |
| 글자(`Spare`, 심볼 S) | `#F3F6F2` | `#0E1A15` |
| 브랜드 초록(`on`, 전원 막대) | `#14B86A` | `#0A8A4E` |

밝은 배경의 초록은 흰 바탕 대비를 위해 한 단계 어둡게 했다(흰 바탕 대비 약 4.4:1, 로고 크기에서 충분). 본문 글자색으로 쓸 때는 더 어두운 값을 웹 디자인 토큰(S23)에서 정한다.

## 쓰는 법
- 여백: 로고 둘레에 심볼 높이의 1/4 이상을 비운다.
- 최소 크기: 가로 로고 높이 20px, 심볼 16px.
- 하지 않는 것: 색 바꾸기(위 두 조합 외), 늘리거나 기울이기, 그림자·외곽선 추가, 사진 위에 직접 얹기.

## 쓰는 곳
- 진행 보드(`scripts/board.mjs`): 웹 보드 머리의 심볼·파비콘, 터미널 보드의 워드마크 색.
- 상태줄(`scripts/statusline.mjs`): 워드마크 색.
- 웹(S23): 디자인 토큰의 출발점. `apps/web/public`으로 복사해 쓴다.
- 설치 프로그램(S21): `spareon-icon.svg`에서 ICO를 만든다.
