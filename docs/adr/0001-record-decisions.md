# 0001. 되돌리기 어려운 결정은 ADR로 기록한다

- 상태: 채택
- 날짜: 2026-10-08
- 차수: S00

## 맥락
이 저장소는 사람이 자리에 없는 동안 여러 세션의 Claude가 차수별로 이어서 만든다(`prompts/_PROTOCOL.md`). 세션 사이에 맥락이 끊기므로 "왜 이렇게 했는가"가 코드에 남지 않으면 다음 차수가 결정을 뒤집거나 같은 검토를 반복한다. 돈(원장)·손님 보호·보안처럼 되돌리기 어려운 영역이 많다.

## 결정
- 되돌리기 어려운 결정(기술 스택 변경, 데이터 모델, 프로토콜, 돈의 흐름, 보안 경계, 외부 서비스 선택)은 `docs/adr/NNNN-kebab-title.md`로 남긴다.
- 형식은 `docs/adr/0000-template.md`를 따른다. 필수 절: 맥락 / 결정 / 검토한 대안 / 결과와 트레이드오프 / 재검토 조건.
- 번호는 기존 최댓값 + 1, 4자리. 채택된 ADR은 고치지 않고, 바뀌면 새 ADR로 대체하고 옛 ADR의 상태를 `대체됨(→ NNNN)`으로 바꾼다.
- `scripts/check-docs.mjs`가 파일 이름, 번호 중복, 필수 절을 검사하고 `pnpm verify`의 `docs` 단계에서 실행된다.

## 검토한 대안
| 대안 | 장점 | 단점 | 버린 이유 |
|---|---|---|---|
| 차수 PLAN/REPORT에만 기록 | 파일 수가 적다 | 결정이 차수 문서에 흩어져 찾기 어렵다 | 나중 차수가 근거를 찾을 수 없다 |
| 코드 주석으로만 기록 | 코드 옆에 있다 | 대안·재검토 조건을 담기 어렵고 여러 파일에 걸친 결정은 둘 곳이 없다 | 범위가 좁다 |
| 외부 위키 | 편집이 쉽다 | 저장소와 버전이 어긋나고 오프라인 세션에서 못 읽는다 | 단일 진실 원천이 깨진다 |

## 결과와 트레이드오프
- 결정마다 문서를 쓰는 비용이 든다. 대신 이후 차수가 근거를 읽고 일관되게 판단할 수 있다.
- 형식 검사가 자동이라 빠진 절이 있으면 게이트에서 막힌다.

## 재검토 조건
- ADR이 50개를 넘어 찾기 어려워지면 색인(`docs/adr/README.md`)이나 분류를 도입한다.
- 사람 팀이 생겨 다른 결정 도구(RFC 등)를 쓰기로 하면 다시 본다.
