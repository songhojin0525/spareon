# 0016. 손님 우선: 모든 불확실한 상태의 기본값은 '멈춤'이다 (fail-safe)

- 상태: 채택
- 날짜: 2026-10-08
- 차수: S01

## 맥락
- 사장님께 드리는 약속은 하나다: "손님이 앉으면 바로 멈춥니다. 게임에 영향이 없습니다."(S18) 이 약속이 한 번이라도 깨지면 매장은 떠난다. 손님 경험 > 수익(BUSINESS_CONTEXT 13절 1번, CLAUDE.md 절대 규칙 1).
- 에이전트는 남의 PC에서 돌고, 정보는 자주 불완전하다: 헬퍼가 죽음, 서버 연결 끊김, GPU 정보를 못 읽음, 시계가 틀림, 에이전트 일부가 멈춤.
- 돈 쪽에도 같은 원칙이 필요하다: 원장이 어긋났는데 돈이 계속 움직이면 피해가 커진다.

## 결정
- **원칙**: 작업 가능(Eligible)은 "모든 조건이 확실히 참"일 때만이다. 정보가 없거나, 오래됐거나, 읽기 실패하거나, 해석이 애매하면 작업 불가다. 이 원칙을 약하게 하는 변경은 금지한다(절대 규칙 1).
- **에이전트에서 '멈춤'이 되는 경우(전부 테스트 대상)**:
  - 손님 입력 감지 → 즉시 선점(입력 → 프로세스 종료 0.5초, 입력 → VRAM 해제 p95 2초).
  - 헬퍼 하트비트 1초 넘게 없음, 파이프 오류, 헬퍼 신원 확인 실패.
  - 전체 화면 앱, 차단 목록 앞 창, 우리 외 프로세스의 GPU 3D 사용, (추가 제안) 오디오 재생·GPU 비디오 디코드 사용.
  - GPU 정보 읽기 실패(nvidia-smi 없음·실패), GPU 온도 한도 초과.
  - 매장 일정 밖, 일시정지·킬스위치, 서버 연결이 재개 창(10초) 넘게 끊김 — 킬스위치를 받을 수 없는 상태를 10초로 묶는다.
  - **로컬 데드맨 스위치**: 적격 판정 루프가 '적격 임대'를 250ms마다 갱신하고, 1초 넘게 갱신되지 않으면 잠금을 공유하지 않는 감시 경로가 런타임 Job Object를 종료한다(에이전트 일부가 교착돼도 멈춤).
  - 선점 뒤 다시 작업하려면 `minIdleMinutes`(기본 10분)를 처음부터 채운다.
  - 다운로드도 같은 신호로 즉시 일시정지(매장 회선은 게임용).
- **선점 경로의 우선순위**: 선점은 다른 모든 일보다 먼저다. 서버에 알리는 일(`job.preempted`)은 종료를 기다리게 하지 않는다(병렬). 서버 연결이 없어도 선점은 로컬에서 끝난다.
- **서버에서 '멈춤'이 되는 경우**: 킬스위치(노드·매장·전체)는 지속 저장되고 재연결 시 `auth.ok`에 실려 다시 적용된다. 원장 대사 차이 → `ledger_frozen`(외부 환전·성숙·정산 기록 정지). 환율 노후 → 외부 환전·테스트 충전 정지. 준비금 비율 미달 → 외부 환전 거부.
- **멈춤의 비용은 플랫폼이 진다**: 선점된 작업은 재배정·이어쓰기로 구매자에게 넘어가고, 그 비용(재처리)은 플랫폼 부담이다. '멈추면 손해'라는 이유로 멈춤을 늦추는 코드를 만들지 않는다.

## 검토한 대안
| 대안 | 장점 | 단점 | 버린 이유 |
|---|---|---|---|
| 정보가 없으면 마지막 상태 유지 | 가동률 높음 | 헬퍼가 죽은 사이 손님이 앉아도 계속 연산 | 약속 위반 |
| 우아한 종료(현재 토큰 생성 끝낸 뒤 멈춤) | 출력 손실 적음 | 수백 ms~수 초 지연, 게임 시작과 겹침 | 0.5초 목표 위반 |
| 서버가 선점 결정 | 중앙 통제 | 네트워크 지연·끊김에 손님 보호가 묶임 | 로컬이 결정하고 서버는 통보받는다 |
| GPU 우선순위 낮추기(멈추지 않고 양보) | 작업 유지 | GPU 메모리를 계속 점유, 게임 프레임 저하 | 손님 영향 |

## 결과와 트레이드오프
- 쉬워지는 것: 사장님께 하는 약속이 코드 구조(판정 순수 함수 + 진리표 테스트)로 보장된다.
- 어려워지는 것: 가동률이 떨어진다(헬퍼 문제·짧은 끊김에도 멈춤). 오탐 멈춤은 수익 손실이지만 손님 피해는 없다 — 의도된 트레이드오프다.
- 이 원칙 때문에 생기는 '불필요한 멈춤' 비율을 지표로 본다(S17·S29). 너무 높으면 원인(헬퍼 안정성 등)을 고치지, 원칙을 완화하지 않는다.

## 재검토 조건
- 없음(원칙). 세부 임계값(1초, 10초, 10분)은 실기·파일럿 측정으로 조정하되, 방향은 '더 빨리 멈춤'으로만 바꾼다. 늦추는 조정은 새 ADR과 실측 근거가 필요하다.
