# S28 · 보안 감사

| 항목 | 값 |
|---|---|
| 의존 | S22, S27 |
| 권장 모델 | Opus 5.5 (effort 최대) |
| 규모 | XL |
| 사람 필요 | 없음 |

이 차수는 `prompts/_PROTOCOL.md`를 따른다.

## 목표
파일럿으로 실제 매장과 실제 사람 앞에 내놓기 전에, 공격자 입장에서 전체를 감사하고 높음·치명 문제를 0으로 만든다. 돈(원장·준비금), 손님 PC, 구매자 데이터, 서명 키 — 네 가지 자산을 중심으로.

## 먼저 읽을 것
- `docs/THREAT_MODEL.md`, `docs/AGENT_SECURITY.md`, `docs/SIGNING.md`, `docs/PERMISSIONS.md`, `docs/E2E_REPORT.md`, 모든 차수 REPORT의 적대적 검토 결과 중 '안 고친 이유'가 적힌 항목

## 산출물
- `docs/SECURITY_REVIEW.md` — 발견 표(ID, 영역, 심각도, 내용, 재현, 상태, 회귀 테스트 위치)
- `docs/KEY_MANAGEMENT.md` — 서명 키·암호화 키·API 비밀값의 보관, 교체, 유출 대응
- 수정 커밋 + 회귀 테스트
- CI 보안 검사 단계(의존성 취약점, 비밀값 검사, 정적 분석)

## 상세 요구사항

### 1. 영역별 감사 (영역마다 `adversarial-reviewer` 서브에이전트를 '감사 모드'로 따로 호출해 맥락을 깨끗하게)
1. 인증·세션·CSRF·비밀번호·계정 열거
2. 인가: 모든 API에 대해 역할·소유권 검사(권한 표와 실제 라우트 목록을 자동 대조하는 테스트 — 표에 없는 라우트가 있으면 실패)
3. 구매자 API·배치: 입력 검증, 크기·속도 제한, 파일 처리, IDOR
4. WebSocket 게이트웨이: 인증 전 처리, 재전송, 자원 고갈, 복제 탐지 우회
5. 돈: 원장 우회 경로, 반올림, 경합, 멱등 키 충돌, 준비금 가드 TOCTOU, 조정·수동 정산 권한
6. 외부 제공자: API 키 유출, SSRF(사용자 입력이 URL에 들어가는 곳), 응답 신뢰
7. 아티팩트·업데이트: 서명 검증 우회, 경로 조작, 다운그레이드 공격, 키가 서버에 없는지
8. 에이전트: 권한 상승, IPC, 파일 ACL, 데이터 잔존, 손님 조작
9. 웹: XSS, 클릭재킹(프레임 금지 헤더), 오픈 리디렉트, CSP
10. 로깅·개인정보: 프롬프트·키·개인정보가 남는 곳 전수 검사(로그, 에러, 지표 라벨, 감사 데이터)
11. 공급망: 잠금 파일, 의존성 취약점(`pnpm audit`, `govulncheck`), 라이선스 검사(허용 목록 외 라이선스 발견 시 실패), 빌드 재현성
12. 비밀값: 저장소 전체 비밀값 검사(gitleaks 등, 설치 불가 시 정규식 검사 스크립트)

### 2. 처리 기준
- 치명·높음: 반드시 수정 + 회귀 테스트.
- 중간: 수정하거나, 수용 사유 + 완화 + 재검토 시점.
- 낮음: 목록화.

### 3. 키 관리 문서
- 서명 개인키는 서버·CI에 두지 않고 오프라인(또는 하드웨어 키) 보관을 권장하고, 1인 운영 현실에 맞는 절차(어디에 백업, 누가, 서명은 언제 어떻게)를 적는다. 유출 시: 키 교체 → 새 공개키 배포 → 이전 키 폐기 순서와 그 사이 위험.
- DB 데이터 암호화 키 교체 절차(키 ID로 점진 재암호화).

## 하지 말 것
- 실제 외부 시스템 공격·스캔
- 발견을 숨기거나 심각도를 낮춰 적기

## 수용 기준
1. `pnpm verify` 통과(보안 검사 단계 포함)
2. 치명·높음 미해결 0
3. 권한 표 ↔ 라우트 자동 대조 테스트 존재·통과
4. 프롬프트·키 잔존 전수 검사 결과 0(테스트로 자동화된 부분 + 수동 확인 목록)
5. `docs/SECURITY_REVIEW.md`, `docs/KEY_MANAGEMENT.md` 완성

## 적대적 검토 포인트
- 감사 범위에서 빠진 경로(관리용 CLI, 개발 엔드포인트가 운영에서 열리는지)
- '수용'으로 처리된 항목 중 실제로는 높음인 것
- 회귀 테스트가 실제 취약점을 재현하는지

## 선택 확장
- 보안 헤더·CSP 자동 점검 테스트
- 간단한 버그 신고 안내(`SECURITY.md`)
