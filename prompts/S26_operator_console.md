# S26 · 운영자 콘솔

| 항목 | 값 |
|---|---|
| 의존 | S08, S09, S13, S21, S23 |
| 권장 모델 | Sonnet 5.5 |

이 차수는 `prompts/_PROTOCOL.md`를 따른다.

## 목표
혼자 운영하는 창업자가 한 화면에서 사업 전체를 보고 조치할 수 있게 한다: 노드 현황, 작업, 검증·사기 대응, 원장 대사, 준비금, 가격표, 모델, 에이전트 배포, 기능 플래그, 전체 멈춤, 수동 정산 기록, 감사 로그. 위험한 조작은 실수하기 어렵게.

## 먼저 읽을 것
- `docs/PERMISSIONS.md`, `docs/VERIFICATION.md`, `docs/LEDGER.md`, `docs/PRICING.md`, `docs/UPDATES.md`, `docs/WEB.md`, `docs/MVP.md`(SLO)

## 산출물 (모두 `/ops` 아래)
- 개요: 연결된 노드 수(매장별), 작업 처리량·실패율, 선점 지연 분포, 원장 대사 상태(정상/차이 — 차이면 화면 상단 빨간 배너), 준비금 비율, 오늘 외부 지출, 검증 실패 추이
- 노드·매장: 검색·필터 표, 노드 상세(상태 이력, 평판, 검증 기록, 버전), 격리·해제(사유 필수)
- 작업: 검색(상태·모델·매장·기간), 작업 상세(시도 목록, 선점·이어쓰기 경과, 과금) — **프롬프트·출력 내용은 보이지 않음**(길이·해시만)
- 검증 대기열: S13의 검토 항목, 근거(점수·비교·이력), 결정 버튼(유지 / 해제 / 회수 확정), 감사
- 돈: 대사 결과 이력, 원장 계정 조회·명세, 준비금·부채·비율, 가드 거부 기록, **수동 정산 기록** 입력(매장, 금액, 송금 참조번호 — 실제 송금은 은행에서 하고 여기서는 기록만), 조정(사유 필수)
- 가격: 가격표 초안 만들기 → 변경 미리보기(차이표) → 예약 활성화, 환율 입력, 페그·한도 설정
- 모델: 등록 현황, 활성화 게이트 결과, 은퇴
- 배포: 에이전트 릴리스, 단계적 배포 비율 조정, 일시정지·롤백, 매장별 버전 고정, 건강 지표
- 설정: 기능 플래그(위험 플래그는 잠금 표시 — `CASHOUT_ENABLED`처럼 코드상 불가능한 것은 '법률 검토 필요'로 회색), 전체 멈춤 스위치
- 감사 로그 뷰어(필터, 내보내기)

## 상세 요구사항

### 1. 위험한 조작의 안전장치
- 전체 멈춤, 가격 활성화, 배포 100%, 회수 확정, 조정, 수동 정산 기록: 확인 대화상자에 대상·영향 요약 + 확인 문구 입력(예: 매장 이름이나 "전체 멈춤" 입력).
- 모든 조작은 서버에서 다시 권한·유효성 검사, 감사 기록.

### 2. 서버 API
- 필요한 운영자 집계·조회 API를 서버에 추가(권한: operator만). 대용량 표는 커서 페이지네이션.

### 3. 시험
- E2E: 사기 노드(nodesim) → 검증 실패 → 대기열 → 회수 확정 → 원장 반영 / 가격 초안 → 미리보기 → 활성화 / 배포 비율 변경 / 전체 멈춤 → 가짜 에이전트들 pause 수신 / 수동 정산 기록 → 사장님 화면에 표시.
- 권한: 사장님·구매자 계정으로 `/ops` 화면과 운영자 API 접근 → 전부 거부(403).
- axe(데스크톱 위주, 모바일은 핵심 화면만).

- 원장 직접 수정(조정은 원장 거래로만)
