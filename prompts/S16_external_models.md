# S16 · 외부 모델 환전 (Claude API 어댑터)

| 항목 | 값 |
|---|---|
| 의존 | S08, S14 |
| 권장 모델 | Opus 5.5 |
| 규모 | L |
| 사람 필요 | 끝에 선택 — 실제 API 키로 1회 연동 확인(비용 발생 가능) |

이 차수는 `prompts/_PROTOCOL.md`를 따른다.

## 목표
"1크레딧으로 Opus도, Sonnet도 쓸 수 있다"를 구현한다. PC방에서는 돌릴 수 없는 모델(가중치 비공개)이므로, 준비금으로 제공사 API를 사서 내준다(BUSINESS_CONTEXT 6절). 핵심은 **준비금 가드를 절대 넘지 않으면서**, 실제 사용량대로 정확히 정산하는 것이다. 기본값은 모의(mock) 제공자이며 실제 호출은 세 겹의 명시적 설정이 있어야만 일어난다.

## 먼저 읽을 것
- `docs/PRICING.md`(준비금 가드·한도·페그), `docs/LEDGER.md`(EXTERNAL_EXCHANGE), `docs/BUYER_API.md`, `docs/BUSINESS_CONTEXT.md` 3·6·10절

## 산출물
- `apps/server/src/providers/` — `ModelProvider` 인터페이스, `MockProvider`(결정적, 기본값), `AnthropicProvider`
- 카탈로그 설정: 외부 모델 항목(우리 모델 ID ↔ 제공사 모델 ID, 원가, 마진 bps, 스트리밍 지원)
- `docs/EXTERNAL_MODELS.md` — 흐름, 가드, 정산, 실패 처리, 실제 연동 절차, 약관 확인 항목

## 상세 요구사항

### 1. 안전 스위치 (세 겹)
- 실제 호출 조건: `EXTERNAL_PROVIDERS=anthropic` **그리고** `ANTHROPIC_API_KEY` 존재 **그리고** `EXTERNAL_LIVE_CONFIRM=yes`. 하나라도 없으면 MockProvider.
- 테스트 환경에서는 네트워크 연결 자체를 막는다(undici MockAgent 또는 nock의 net connect 차단). 테스트 중 실제 외부 호출이 시도되면 테스트 실패.
- 하루 달러 지출 상한(전체·구매자별, 설정값). 넘으면 거부.

### 2. 제공사 사양 확인
- Anthropic Messages API의 현재 사양(엔드포인트, 헤더, 버전 헤더, 스트리밍 이벤트 형식, usage 필드, 모델 ID)은 **웹 검색으로 공식 문서를 확인**하고 날짜와 함께 ADR에 기록한다. 확인할 수 없으면 '확인 필요'로 표시하고 기록된 fixture 기반으로만 구현한다. 추측으로 채우지 않는다.
- 참고(2026-10 기준, 연동 전 재확인): 모델 ID 예시 `claude-opus-5-5`, `claude-sonnet-5-5`, `claude-haiku-4-5-20251001`. 정가는 BUSINESS_CONTEXT 3절 표.

### 3. 흐름
1. 구매자 요청(`/v1/chat/completions`, model=외부 모델) → 견적: 최대 비용(입력 추정 + max_tokens) → 크레딧 홀드 + **준비금 예약**(가드 판정과 예약을 원자적으로, S08)
2. 제공사 호출(스트리밍이면 제공사 SSE를 OpenAI chunk 형식으로 변환)
3. 응답의 **실제 usage**로 정산: 크레딧 캡처(원가 × (1 + 마진) → 페그로 크레딧 환산) + 준비금 실제 지출 기록(`EXTERNAL_EXCHANGE`), 남은 홀드·예약 해제
4. 실패(타임아웃, 5xx, 429)는 지터 있는 재시도(retry-after 존중, 횟수 상한) 후 최종 실패면 전부 해제. 제공사가 일부라도 과금했을 수 있는 경우(스트리밍 도중 끊김)는 받은 usage 기준으로 정산하고 기록.

### 4. 기록
- `external_usage`: 작업 ID, 제공사, 모델, 제공사 요청 ID, 입력·출력 토큰, 원가 µUSD, 시각. 프롬프트는 저장하지 않는다.
- 운영자 지표: 오늘 외부 지출, 준비금 비율, 가드 거부 수.

### 5. 약관
- 외부 모델을 우리 서비스로 재판매하는 것이 제공사 약관상 허용되는 조건을 HUMAN_TODO에 "법률·약관 확인"으로 추가(이 차수에서 판단하지 않는다).

## 하지 말 것
- 기본 설정에서 실제 외부 호출
- 외부 모델 요청을 PC방 노드로 보내기
- 프롬프트·응답 저장

## 수용 기준
1. `pnpm verify` 통과(테스트 중 외부 네트워크 호출 0 — 차단 장치로 보장)
2. Mock으로 `/v1/chat/completions`(외부 모델, 비스트리밍·스트리밍) 호출 → 정확한 크레딧 캡처·준비금 지출
3. 준비금 가드: 비율 미만이 될 요청 거부, 동시 요청 경합에서도 비율 유지
4. 하루 지출 상한 테스트, 재시도·최종 실패 시 전부 해제 테스트
5. 스트리밍 변환 테스트(기록된 fixture), 도중 끊김 시 부분 정산 테스트
6. 실제 연동 절차(`docs/EXTERNAL_MODELS.md`)와 HUMAN_TODO 항목(비용 발생 가능 경고 포함)

## 적대적 검토 포인트
- 원가 계산 단위 실수(100만 토큰당 가격 ↔ µUSD ↔ 크레딧)
- 가드 판정과 실제 지출 사이 경합, 정산 누락으로 준비금이 장부보다 실제로 더 빠지는 경로
- API 키 노출(로그, 에러, 클라이언트 응답)

## 선택 확장
- 제공사 Batch API(50% 할인)를 배치 요청에 쓰는 경로 설계 문서
- 프롬프트 캐시 사용 시 원가 절감 반영
