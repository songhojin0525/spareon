## 산출물
- `README.md` 갱신(무엇인가, 구조, 시작하기, 문서 지도)
- `docs/INDEX.md` — 모든 문서의 지도(누가 읽는지별: 창업자 / 개발 / 사장님 / 운영)
- `docs/ARCHITECTURE.md` 등 설계 문서를 '실제 구현' 기준으로 갱신(설계와 달라진 점 절)
- ADR 상태 정리(채택 / 대체됨 / 폐기)
- `docs/KNOWN_LIMITATIONS.md` — 알려진 한계와 영향
- `docs/NEXT.md` — 로드맵 2단계 준비: 법률 검토, 실제 결제(PG) 연동, 코드 서명 인증서, 사업자 등록, 파일럿 결과 반영, 열린 질문(BUSINESS_CONTEXT 12절) 갱신 제안
- `CHANGELOG.md`, 버전 0.1.0(모든 패키지 + 에이전트), 태그 `v0.1.0`
- `HUMAN_TODO.md` 정리(중복 제거, 우선순위, 예상 소요)

## 상세 요구사항
1. `node scripts/check-skeleton.mjs` → `SKELETON(` 표시 0개. 남아 있으면 대체하거나, 정말 v0.1 범위 밖이면 기능 플래그로 잠그고 KNOWN_LIMITATIONS에 기록(표시는 제거).
2. `node scripts/check-docs.mjs` 통과(깨진 링크, 없는 차수 참조 0).
3. `pnpm verify` + `node scripts/e2e-system.mjs --scenario all` 1회 전체 통과(결과 요약을 REPORT에).
4. MVP.md의 'v0.1 완료' 정의 항목별 충족 여부 표(충족 / 실기 확인 대기 / 미충족 + 사유).
