## 목표
모든 부품을 실제로 함께 띄우고, 현실보다 가혹하게 흔들어서 **돈이 틀리지 않고, 작업이 사라지지 않고, 손님 보호가 깨지지 않는지** 증명한다. 찾은 버그는 고치고 회귀 테스트를 남긴다. 결과는 파일럿 전에 "어디까지 믿어도 되는지"를 알려 주는 보고서다.

## 먼저 읽을 것

## 산출물
- `scripts/e2e-system.mjs` — 전체 시스템 오케스트레이터: 임시 Postgres, 서버(2 인스턴스 옵션), 웹(선택), nodesim(가상 노드 200+, 사기 비율 지정, 시간 압축 손님 패턴), 구매자 부하 생성기
- `tools/loadgen/` — 대화형(스트리밍)·배치·외부 모델(Mock) 혼합 부하, 연결 끊기·취소 섞기
- 장애 주입 도구(`packages/testkit/chaos/`): TCP 프록시(지연·끊김·대역폭 제한), 서버 프로세스 강제 종료·재시작, DB 일시 정지(프로세스 정지 신호 등 가능한 방식), 시계 차이 주입(가짜 에이전트)
- `docs/E2E_REPORT.md`
- 발견한 버그 수정 + 회귀 테스트

## 상세 요구사항

### 1. 시나리오 (각각 시드 고정, 3회 반복)
1. **평상시**: 저녁 붐빔 → 새벽 한산 패턴(시간 압축), 대화형 30% + 배치 70%
2. **손님 몰림**: 1분 안에 노드 70%가 동시에 손님 착석(대량 선점) → 재배정·이어쓰기
3. **서버 재시작**: 부하 중 서버 강제 종료 → 재시작 → 에이전트 재연결·작업 이어짐
4. **두 인스턴스**: 서버 2개, 노드가 나뉘어 붙음, 한 인스턴스 종료
5. **DB 지연·일시 정지**: 수 초간 응답 없음
6. **네트워크 불안정**: 노드 일부에 지연·패킷 끊김
7. **사기 물결**: 사기 노드 10% 동시 등장
8. **뱅크런**: 구매자들이 동시에 외부 모델 환전 폭주(Mock)
9. **킬스위치**: 부하 중 전체 멈춤 → 1초 안에 연결된 모든 노드 멈춤 → 해제 후 정상화
10. **업데이트 롤백**: 가짜 새 버전이 일부 노드에서 인증 실패 → 자동 롤백·배포 일시정지

### 2. 매 시나리오 후 검사 (자동)
- 원장 대사 차이 0, 미해결 홀드 0, 이중 캡처 0, 잃어버린 작업 0(모든 작업이 완료·실패·취소·만료 중 하나)
- 준비금 비율이 가드 아래로 내려간 적 없음
- 킬스위치 이후 작업 시작 0건
- 사기 노드 탐지 수치(S13 목표 대비)
- SLO 표: 작업 성공률(구매자 오류 제외), API 오버헤드 p95, 선점 → 재배정 지연, 킬스위치 전파 지연

### 3. 버그 처리
- 불변식 위반이나 SLO 미달을 찾으면: 최소 재현 테스트 작성 → 수정 → 회귀 테스트 → 시나리오 재실행.
- 고칠 수 없는 것(설계 한계)은 보고서에 영향·완화·후속 차수 제안으로 정직하게.

### 4. 보고서 (`docs/E2E_REPORT.md`)
- 시나리오별 결과 표(3회 반복의 최소·중앙·최대), SLO 충족 여부, 발견·수정한 버그 목록(원인 한 줄), 남은 위험, 파일럿 전 꼭 실기로 확인할 것.
- 실행 방법(명령 한 줄)과 소요 시간.

## 하지 말 것
- 불변식을 느슨하게 바꿔 통과시키기
- 무작위 실패를 '불안정한 테스트'로 치부하고 넘어가기(원인을 찾거나 명확히 기록)

## 수용 기준
1. `pnpm verify` 통과
2. 10개 시나리오 × 3회 실행에서 돈·작업 불변식 위반 0
3. SLO 표 작성, 미달 항목은 원인·대응 기록
4. 발견 버그마다 회귀 테스트 존재
5. `node scripts/e2e-system.mjs --scenario all`로 전체 재실행 가능
