## 왜 중요한가
비트코인은 정답 확인이 즉시지만, AI는 노드가 정말 그 모델로 성실히 돌렸는지 확인하기 어렵다(BUSINESS_CONTEXT 4절). 검증이 약하면 사기 노드가 크레딧을 빼 가고, 너무 엄격하면 성실한 PC방이 억울하게 격리된다. 이 차수는 **사기는 빨리 잡고, 성실한 노드의 오탐은 극히 드문** 검증 체계를 만들고, 적대적 시뮬레이션으로 수치를 증명한다.

## 상세 요구사항

### 1. 검증 방법
- **카나리아**: 신뢰 노드(운영자가 지정한 기준 노드)에서 그리디(temperature 0, seed 고정)로 미리 만든 정답이 있는 작업. 노드별로 하루 일정 횟수, 일반 작업과 구별되지 않게 섞는다(작업 형태·길이·시간대를 실제 분포에서 표본).
- **중복 실행**: 일반 작업의 일정 비율(기본값은 S07 추천)을 **다른 매장의** 노드에 그리디 모드로 한 번 더 돌린다(같은 매장끼리 짜고 치는 것을 막기 위해). 원 작업이 그리디가 아니면 검증용 그리디 쌍을 별도로 만든다.
- **모델 지문**: 모델마다 출력이 확실히 갈리는 짧은 프롬프트 집합. 다른(더 싼) 모델로 바꿔치기한 노드를 잡는다.
- **토큰 수 교차 확인**: S12가 표시한 보고값 불일치 작업.

### 2. 비교와 판정
- GPU가 다르면 그리디도 몇 토큰 뒤부터 갈라질 수 있다. 그래서 비교는 "앞 K토큰 완전 일치(기본 K=32) + 전체 정규화 편집 거리"로 점수화하고, 임계값은 설정값.
- 판정: pass / fail / inconclusive. 중복 실행에서 둘이 다르면 제3 노드(가능하면 신뢰 노드)로 다수결. 한 번의 fail로 처벌하지 않는다 — 판정이 확정된 것만 평판에 반영.

### 3. 평판
- 베타 분포 사후 평균 형태(성공·실패 가중 누적, 시간 감쇠). 공식과 파라미터를 문서화.
- 평판은 매칭 점수(S12)와 검증 빈도(낮은 평판 = 더 자주 검증)에 반영.
- 격리 기준: 창(기본 7일) 안 확정 실패 N회 또는 평판 임계 이하. 격리되면 작업 제안 중단 + 사장님·운영자 알림.

### 4. 회수
- 확정된 부정 시도에 연결된 **미성숙 수익**은 회수(S06 `EARNING_CLAWBACK`). 영향받은 구매자에게는 재실행 또는 환불(정책 문서화).
- 이미 성숙한 수익은 자동 회수하지 않고 운영자 검토 대상으로 올린다(사람 판단).

### 5. 운영자 검토 대기열
- 격리·회수·애매한 판정을 모아 근거(비교 결과, 점수, 노드 이력)와 함께 보여 주는 API. 결정(유지·해제·회수 확정)은 감사 기록.

### 6. 적대적 시뮬레이션 (S12 하네스 확장)
- 노드 유형: 성실(GPU 비결정성 있음 — 확률 p로 무작위 위치부터 갈라짐), 게으름(싼 모델 사용), 쓰레기 출력, 재사용(이전 출력 재전송), 잘라 먹기(출력 일부만 생성하고 토큰 수 부풀림), 간헐적 사기(10%만 속임), 같은 매장 공모.
- 측정: 유형별 탐지까지 걸린 작업 수(중앙값, 90백분위), 탐지 전까지 빼 간 크레딧, 성실 노드 1,000개 × 가상 30일의 오탐 격리 비율, 검증 비용(전체 연산 대비 %).
- 목표: 게으름·쓰레기·재사용은 50작업 이내 탐지(90백분위), 성실 노드 오탐 격리 < 0.5%, 검증 비용 ≤ 10%. 목표를 못 맞추면 임계값 탐색 결과와 트레이드오프를 보고서에 정직하게.
- `VERIFICATION_REPORT.md`: 임계값별 탐지율·오탐률 표(ROC 형태), 추천 설정.

## 하지 말 것
- 성숙한 수익의 자동 회수
- 구매자 프롬프트 내용을 사람에게 보여 주는 검토 화면(비교는 해시·점수·길이 중심, 내용 열람은 별도 권한·감사 — v0.1에서는 열람 기능 없음)

## 수용 기준
1. `pnpm verify` 통과
2. 적대적 시뮬레이션 결과가 목표를 충족하거나, 미달 항목마다 원인·대안이 보고서에 있음
3. 회수 원장 테스트: 회수 후 대사 차이 0, 구매자 환불 정확
4. 카나리아 구별 불가 테스트: 카나리아와 일반 작업의 메시지 형태가 노드 쪽에서 구별되지 않음(필드·크기 분포 비교)
5. 같은 매장 공모 시나리오에서 중복 실행이 다른 매장으로 배정됨을 확인

## 적대적 검토 포인트
- 노드가 카나리아를 알아챌 수 있는 단서(고정 프롬프트, 특정 시간대, 길이)
- 평판 세탁(재등록으로 평판 초기화) — S10 재부착과 연결해 막혔는지
- 오탐으로 성실한 사장님 수익을 회수하는 경로

## 선택 확장
- 검증 기록 해시 체인(사후 변조 탐지)
- 매장 단위 위험 점수(같은 매장의 여러 노드가 동시에 이상할 때)
