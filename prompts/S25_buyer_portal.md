## 목표
첫 구매자(로드맵 2단계)가 가입부터 첫 API 호출까지 5분 안에 끝내게 한다: 키 발급, 테스트 충전, 모델별 가격과 "1크레딧으로 얼마나 쓰는지", 플레이그라운드, 배치 업로드, 사용 내역. 크레딧이 '여러 모델로 바뀌는 돈'이라는 이 사업의 핵심을 구매자가 화면에서 체감하게 한다.

## 먼저 읽을 것
- `docs/BUSINESS_CONTEXT.md` 3·5절(환율표), `docs/BUYER_API.md`, `docs/BATCH_API.md`, `docs/EXTERNAL_MODELS.md`, `docs/PRICING.md`, `docs/WEB.md`

## 산출물 (모두 `/app` 아래)
- 홈: 잔액(크레딧, 원화 환산 '약'), 이번 달 사용량, 빠른 시작
- API 키: 만들기(한 번만 보여 주기 + 복사), 이름, 스코프, 한도, 폐기, 마지막 사용 시각, 키별 개인정보 옵션(신뢰 노드만, 결과 보관 안 함)
- 크레딧: **테스트 충전**(원화 입력 → 받을 크레딧 미리보기 → 충전, "테스트 충전 — 실제 결제 아님" 명확히), 내역(원장 명세)
- 모델과 환율표: 모델별 100만 토큰당 가격, **1크레딧으로 입력·출력 각각 몇 토큰**(BUSINESS_CONTEXT 3절 표 형식), 오픈소스 / 외부 모델 구분, 오늘 외부 모델 환전 한도 잔여
- 플레이그라운드: 모델 선택, 대화(스트리밍), 요청마다 사용 토큰·비용 표시, 코드로 보기(curl / Python / JavaScript — OpenAI SDK에 base_url)
- 배치: JSONL 끌어다 놓기 → 검증 결과(줄별 오류) → 견적·홀드 확인 → 진행률 → 결과 내려받기, 취소
- 사용 내역: 모델별·일별 표와 그래프, CSV 내보내기
- 문서: 빠른 시작, 가격, 용량 부족(503) 대응, 개인정보 안내(민감 정보 넣지 말 것 — PC방 PC에서 처리됨을 정직하게)

## 상세 요구사항

### 1. 플레이그라운드 인증
- 플레이그라운드는 구매자의 웹 세션으로 서버를 호출한다(API 키를 브라우저에 두지 않음). 서버에 세션 인증용 채팅 경로를 추가하되 과금·한도·권한은 API 키 경로와 같은 코드로.

### 2. 정확성
- 화면의 비용·잔액은 서버 응답(원장)에서만. 플레이그라운드 응답 후 잔액 감소 = 표시 비용(테스트).
- 환율표 숫자는 서버의 가격·페그 API에서 계산된 값(화면 계산 금지).

### 3. 개인정보 고지
- 첫 키 생성·첫 플레이그라운드 사용 시 "요청은 PC방의 PC에서 처리됩니다. 개인정보·비밀 정보는 넣지 마세요" 안내와 확인. 신뢰 노드 옵션 설명.

### 4. 시험
- E2E: 가입 → 테스트 충전 → 키 발급(한 번만 보임 확인) → 플레이그라운드 스트리밍 → 잔액 감소 = 표시 비용 → 배치(작은 파일) 완료·결과 내려받기 → 외부 모델(Mock) 호출 → 준비금 가드 거부 시 안내 문구.
- axe, 모바일 스크린샷.
