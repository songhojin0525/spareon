## 목표
남의 매장, 남의 손님 PC에서 도는 프로그램이다. 그 PC를 위험하게 만들지 않고(최소 권한, 열린 포트 없음), 손님이 에이전트를 조작해 이득을 보지 못하게 하고, 구매자 데이터가 PC에 남지 않게 한다. 위협 모델(S01)의 에이전트 관련 항목을 전부 닫거나 '수용한 위험'으로 정직하게 남긴다.

## 먼저 읽을 것
- `docs/THREAT_MODEL.md`(에이전트·손님·복제 행), ADR 0008·0010·0011, `docs/AGENT.md`, `docs/PRESENCE.md`, `docs/RUNTIME.md`, `docs/UPDATES.md`

## 산출물
- 서비스 계정·권한 정리, 파일·파이프 ACL, 키 저장(DPAPI), 나가는 연결 허용 목록, 자기 무결성 확인, 데이터 디스크 기록 감사
- `docs/AGENT_SECURITY.md`, 갱신된 `docs/THREAT_MODEL.md`, `docs/manual-tests/S22.md`

## 상세 요구사항

### 1. 최소 권한
- 서비스 실행 계정 결정(ADR): LocalSystem vs 가상 서비스 계정(`NT SERVICE\SpareonAgent`) vs LocalService. 필요한 권한(헬퍼 실행용 `WTSQueryUserToken`, Job Object, GPU 접근, 영구 폴더 쓰기)을 표로 정리하고, 권한이 큰 작업만 분리할 수 있는지 검토. **세션 0에서 CUDA가 동작하는지**는 KNOWN_UNKNOWNS 항목이므로 실기 체크리스트에 포함하고, 안 될 때의 대안(사용자 세션에서 제한된 런타임 실행 등)을 ADR에 둔다.
- 헬퍼는 사용자 권한, 관리자 요구 없음.

### 2. 파일·IPC 보호
- 영구 폴더 ACL: 서비스 계정 + Administrators만 쓰기, 사용자 읽기 불가(신원 키 보호).
- 신원 개인키: Windows DPAPI(머신 범위 + 추가 엔트로피)로 암호화 저장. `KeyStore` Windows 구현.
- 이름 있는 파이프 ACL 재검토(S18), 연결 클라이언트 PID·세션 확인.

### 3. 네트워크
- 들어오는 포트 없음(캐시 노드의 LAN 포트 제외, 그것도 사설 대역 + 토큰).
- 나가는 연결 허용 목록: 설정된 서버 호스트, 아티팩트 호스트, 매장 LAN 캐시. 다른 호스트로의 리다이렉트 거부.
- TLS 검증 끄는 옵션 없음. (인증서 고정은 운영 부담 때문에 기본 꺼짐 — 선택 확장)

### 4. 데이터가 남지 않게
- 작업 경로에서 디스크 쓰기 감사: 실행기·런타임 연동 코드의 파일 쓰기 호출을 정적 검사(테스트로 강제)하고, 통합 테스트에서 작업 실행 중 영구·임시 폴더에 새로 생긴 파일을 감시해 프롬프트 표식 문자열이 들어간 파일이 0개인지 확인.
- 런타임 프롬프트 로그·캐시 끔(S19) 재확인.
- 크래시 덤프: llama-server 크래시 덤프에 프롬프트가 남을 수 있다. Windows 오류 보고(WER) 로컬 덤프 설정을 런타임 실행 파일에 대해 끄는 방법을 조사해 적용하거나, 불가하면 수용한 위험으로 문서화.

### 5. 무결성
- 시작 시 자기 실행 파일 해시를 설치된 매니페스트와 비교(불일치 → 작업 불가 + 보고).
- 런타임·모델 파일 실행 직전 해시 재확인(크기가 커서 비용이 크면 mtime + 주기 검사로 타협, 근거 기록).

### 6. 손님에 의한 조작
- 손님이 할 수 있는 일(작업 관리자로 헬퍼 종료, 네트워크 케이블, 시계 변경, 가짜 입력 없애기 등)을 나열하고 각각의 결과가 "손님에게 피해 없음 + 부당 이득 없음"인지 확인. 대부분 fail-safe(작업 중단)로 귀결되어야 한다.

### 7. 정적 분석
- `gosec`, `govulncheck`를 CI에 추가, 높음 0개. 예외는 사유와 함께 주석·문서화.

## 하지 말 것
- 백신을 피하기 위한 난독화·패킹
- 손님 활동 내용 수집

## 수용 기준
1. `pnpm verify` 통과, `gosec`·`govulncheck` 높음 0(또는 문서화된 예외)
2. 디스크 기록 감사 테스트 통과(프롬프트 표식 파일 0개)
3. Windows CI: ACL 설정·DPAPI 왕복 테스트 통과(실행 가능한 범위)
4. 위협 모델의 에이전트 항목 전부 '완화(테스트/문서 근거)' 또는 '수용(사유)'
5. `docs/AGENT_SECURITY.md`, `docs/manual-tests/S22.md`(세션 0 CUDA 확인 포함), 상태 `DONE_NEEDS_HUMAN`

## 적대적 검토 포인트
- 권한 상승 경로(쓰기 가능한 폴더의 실행 파일, DLL 탐색 순서, 서비스 경로 따옴표)
- 신원 키 탈취 → 다른 매장 노드 행세
- 보안 기능 실패 시 '계속 진행'하는 경로

## 선택 확장
- 서버 인증서 고정(백업 핀 포함, 기본 꺼짐)
- 에이전트 자가 진단 명령(`spareon-agent doctor`): 권한·ACL·네트워크·GPU·영구성 점검 결과 표
